# byte-compress

A small CLI project written in C for experimenting with data compression algorithms.

## Installation

1. **Clone the repository**:

```bash
git clone https://github.com/ThomasTramarin/byte-compress.git
cd byte-compress
```

2. **Build**:

```bash
make
```

3. **The executable will be in the `build/` folder**:

```bash
./build/bcomp
```

4. **To clean build files**:

```bash
make clean
```
